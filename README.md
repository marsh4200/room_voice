# Room voice

A Home Assistant voice agent that uses its own room and item names.

## Setup

1. Install, then restart Home Assistant.
2. Settings, Devices and services, Add integration, Room voice.
3. Open Room voice in the sidebar, add rooms and items, and save.
4. Settings, Voice assistants, Add assistant, and choose Room voice as the conversation agent.
5. Set each speaker's Assistant to the new one.
